# PS4 USB Controllers Direct

## Controladores
- DualShock 3 (PS3) por USB
- Xbox 360 con cable USB

Version v0.7 para PS4 con GoldHEN.
Firmware probado: 13.02.
Otros firmwares no verificados.

## Instalacion
1. Descargar el archivo ELF desde Releases.
2. Copiarlo a /data/payloads/ en PS4.
3. Conectar el mando por USB.
4. Ejecutar desde GoldHEN PayLoader LaunchPad.
5. Seleccionar usuario.

No ejecutar dos instancias de Control4Free.
Mantener un DualShock 4 disponible.

## Bluetooth
La version original incluye componentes Bluetooth
experimentales. La compatibilidad inalambrica no
esta confirmada. Este binario no fue recompilado:
solo se cambio el nombre del archivo descargable.
